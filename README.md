# TechSolutions Company Profile Website

A modern company profile website for TechSolutions Inc., built with HTML, CSS, and JavaScript. This website showcases the company's products, team, and services.

## Features

- Responsive design that works on all devices
- Interactive product gallery with filtering
- Team showcase
- About us section with company history
- Contact form using Formspree for static site form handling
- Animated sections with AOS library
- Modern UI with gradient accents

## Pages

- **Home**: Company overview and featured products
- **Products**: Complete product catalog with filtering
- **About Us**: Company story, mission, vision, and values
- **Team**: Leadership and engineering team profiles
- **Contact**: Contact form and location information

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Font Awesome Icons
- AOS (Animate On Scroll) Library
- Formspree (for form processing)

## Deployment

This is a static website designed to be deployed on GitHub Pages.

### How to Deploy to GitHub Pages

1. Push this code to a GitHub repository
2. Go to the repository settings
3. Navigate to the "Pages" section
4. Select the main branch as the source
5. Save the settings

The website will be available at `https://[your-username].github.io/[repository-name]/`

## Form Processing

The contact form uses [Formspree](https://formspree.io/) for processing. To make it work:

1. Create a Formspree account
2. Set up a new form
3. Replace `YOUR_FORMSPREE_ID` in the contact.html file with your actual Formspree form ID
